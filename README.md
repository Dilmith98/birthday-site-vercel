# Birthday site

A single-page birthday website: a cake to blow out, a birthday song, a photo gallery and a love letter.

To personalise it, open `index.html` and edit the `SITE` block near the bottom (name, letter and photos). Put photo files in `photos/` and list them as `photos/1.jpg` and so on.

Hosted on Vercel as a static site. No build step is needed.
